# AI 英语带读产品：Codex 实现入口

## 1. 项目目标

实现一个“每天一篇”的 AI 英语精读产品。

用户每天获得一篇 450–600 词的英文知识型短文，并可以在两种模式之间切换：

- **讲解模式**：一位固定的 AI 英语老师，以亲切、有活力、接近知识播客的方式带领用户阅读文章。
- **阅读模式**：用户自由阅读英文原文、播放完整原文音频、逐句播放和临时查看释义。

本项目第一阶段只解决一件事：

> 让用户感觉自己每天都在听一位真人高级英语老师，带自己读懂一篇值得读的英文文章。

## 2. 第一阶段明确不做

- 不做阅读后的口语输出
- 不做练习题和考试
- 不做背单词系统
- 不做积分、签到、连续学习惩罚
- 不做 AI 自由聊天
- 不做实时新闻
- 不做用户上传任意文章
- 不做多个老师或多种人格
- 不做复杂账号系统
- 不做自动生成后直接发布

## 3. 产品默认规格

| 项目 | 默认值 |
|---|---|
| 目标用户 | 中国成年 B1–B2 英语学习者 |
| 内容类型 | 日常问题驱动的知识解释型英文短文 |
| 英文长度 | 450–600 词 |
| 自然段 | 6–8 段 |
| 原文音频 | 3–5 分钟 |
| AI 带读 | 8–12 分钟 |
| 讲解停顿点 | 6–10 个 |
| 深度讲解点 | 3–4 个 |
| 核心表达 | 4–6 个 |
| 更新方式 | 每天发布一篇，提前建立 14–30 篇库存 |

## 4. 推荐实现顺序

按以下顺序开发，不要直接从 AI 生成开始。

### Milestone 1：静态阅读器

- 首页今日文章
- 文章详情页
- 讲解模式 / 阅读模式切换
- 静态假数据
- 播放器
- 段落和句子高亮
- 自动滚动
- 本地阅读进度

### Milestone 2：内容后台

- 文章列表
- 新建与编辑文章
- 句子切分和稳定 ID
- 讲解片段编辑
- 发布状态
- 预览与试听

### Milestone 3：音频系统

- 原文句子音频
- 原文完整音频
- 讲解片段音频
- Fish Audio 适配器
- 局部重新生成
- 音频时长与播放队列

### Milestone 4：AI 内容生产

- 资料整理
- 原创改写
- 文章分析
- 教学导演
- 讲解稿生成
- 编辑审查
- 结构化结果入库

### Milestone 5：质检与发布

- 人工试听
- 事实、英文、教学、听觉检查
- 发布前检查清单
- 简单用户反馈

## 6. Codex 执行原则

- 先实现可运行的纵向切片，再扩展功能。
- 所有生成结果必须可人工编辑，不能把 AI 输出视为不可修改的最终结果。
- 讲解稿必须按片段存储，不能只保存一个十分钟长文本或长音频。
- 原文、讲解字幕、音频和高亮必须共享稳定的段落与句子 ID。
- 音频生成失败不能阻塞文章编辑。
- 页面必须在没有 AI API 的情况下使用种子数据完整运行。
- 不要自行加入本规范明确排除的功能。
