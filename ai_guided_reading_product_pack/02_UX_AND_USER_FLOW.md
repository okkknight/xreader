# UX 与用户流程

## 1. 信息架构

```text
/
├── 今日文章
├── 往期文章 /archive
├── 文章详情 /articles/[slug]
│   ├── 讲解模式
│   └── 阅读模式
└── 后台 /admin
    ├── 文章列表
    ├── 新建文章
    ├── 内容生产
    ├── 讲解编辑
    ├── 音频管理
    └── 发布检查
```

## 2. 首页

首页的目标不是展示大量内容，而是让用户快速开始今天的学习。

### 页面结构

1. 产品名称与极简导航
2. 今日文章主卡
3. 开始讲解
4. 自己阅读
5. 一小块往期入口

### 今日卡片字段

- `title_en`
- `title_zh`
- `dek_zh`
- `topic`
- `difficulty`
- `word_count`
- `guided_duration`
- `cover_image`：MVP 可不做
- `published_at`

### 行为

- 点击“开始讲解”进入讲解模式并从保存位置继续。
- 点击“自己阅读”进入阅读模式并从保存位置继续。
- 用户完成后，按钮变为“再听一次”或“重新阅读”。

## 3. 文章详情页公共区域

### 顶部

- 返回
- 英文标题
- 中文副标题
- 主题、难度、字数、时长
- 讲解 / 阅读模式切换
- 更多菜单：字体、自动滚动、显示讲解字幕

### 文章主体

- 单栏阅读
- 桌面端最大正文宽度约 680–760px
- 每个自然段拥有稳定 ID
- 每个句子可独立高亮
- 当前播放范围使用柔和背景，不使用刺眼边框
- 已播放范围不持续着色，避免页面过脏

### 底部播放器

始终固定或吸附在底部：

- 播放 / 暂停
- 后退 10 秒
- 前进 10 秒
- 当前时间 / 总时长
- 速度：0.8 / 1.0 / 1.2 / 1.5
- 当前片段标题
- 返回当前文字位置

移动端播放器需避免遮挡正文。

## 4. 讲解模式

### 播放队列

讲解模式播放一个结构化队列：

```text
OPENING
ARTICLE_READ
QUICK_EXPLANATION
ARTICLE_READ
DEEP_EXPLANATION
REPLAY
CONTEXT_CONNECTION
...
FINAL_WRAP
```

### 页面行为

- `ARTICLE_READ`：高亮对应句子，使用原文朗读声音。
- `EXPLANATION`：保持对应原文高亮，显示老师字幕。
- `CONTEXT_CONNECTION`：高亮当前段落或下一段标题位置。
- `REPLAY`：再次播放对应原句。
- `FINAL_WRAP`：弱化单句高亮，可高亮全文段落导航。

### 自动滚动规则

- 只在当前高亮区域离开可视区域时滚动。
- 不要每个词都滚动。
- 滚动位置保持在视口上方约 30%–40%。
- 用户手动滚动后，自动跟随临时暂停。
- 显示“回到当前讲解”浮动按钮。
- 用户点击后恢复自动跟随。

### 讲解字幕

- 默认显示当前讲解片段的字幕摘要或完整字幕。
- 用户可关闭。
- 字幕和原文必须视觉区分。
- 不要把中文翻译永久贴在每个英文句子下方。

## 5. 阅读模式

### 原文音频

支持两种播放方式：

1. 连续播放完整文章
2. 点击句子播放当前句

### 中文辅助

- 点击句子显示临时中文释义。
- 再次点击或点击空白处关闭。
- 不默认展开所有中文。

### 单词辅助

MVP 可以使用预生成词汇注释，不需要实时词典。

点击已标注词组时显示：

- 词义
- 此处含义
- 简短例句
- 发音按钮

非标注词可先不支持，避免引入复杂词典系统。

## 6. 模式切换

讲解和阅读模式共享：

- 当前文章
- 当前句子
- 当前段落
- 播放位置映射
- 阅读进度

切换规则：

- 从讲解切到阅读：定位到当前讲解对应原文句子。
- 从阅读切到讲解：跳到覆盖当前句子的最近讲解片段。
- 不强制停止音频，可在切换时平滑切换对应播放器。
- MVP 若实现复杂，可先暂停并提示用户继续播放。

## 7. 结束状态

讲解结束后：

- 显示“今天的讲解到这里”
- 提供“切换到阅读模式，再完整听一遍”
- 提供两项反馈
- 提供“查看往期”

不要弹出强制练习。

## 8. 后台编辑体验

后台编辑页建议分为五个标签：

1. **文章**
2. **分析**
3. **教学设计**
4. **讲解稿**
5. **音频与发布**

### 讲解稿编辑器

左侧：

- 英文文章
- 段落和句子 ID
- 当前讲解覆盖范围

右侧：

- 讲解片段列表
- 类型
- 讲稿
- 对应句子
- 音频
- 重新生成
- 上移 / 下移
- 删除 / 新增

必须允许人工直接修改讲稿。

## 9. 可访问性与基本体验

- 所有播放器按钮有可读标签。
- 支持键盘空格播放暂停。
- 文字颜色满足基本对比度。
- 用户选择的字体大小保存在浏览器。
- `prefers-reduced-motion` 下减少平滑滚动。
- 页面刷新后恢复到上次位置。
