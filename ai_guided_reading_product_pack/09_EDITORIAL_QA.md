# 编辑与质量控制

## 1. 质检原则

产品质量主要由讲稿决定。所有课程在发布前必须经过：

1. 事实检查
2. 英文检查
3. 教学检查
4. 讲稿检查
5. 音频试听
6. 页面预览

任何一层出现阻断问题都不能发布。

## 2. 事实检查

### 检查项

- 每个核心事实能追溯到来源
- 没有把假设写成确定事实
- 没有夸大研究结论
- 没有把相关性写成因果
- 时间、数字、人名和机构正确
- 文章没有加入事实卡外信息
- 讲稿没有在解释时新增未经核实事实

### 阻断问题

- 核心结论错误
- 来源冲突未披露
- 数据错误
- 错误归因
- 讲解扩大原文结论

## 3. 英文检查

评分 1–5：

- 自然度
- 清晰度
- B1–B2 适配
- 段落推进
- 朗读自然度
- 非模板化
- 原创表达风险

### 常见问题

- 每段都先下定义再总结
- “In today’s fast-paced world”
- “It is important to note that”
- 过度使用 however、moreover、in conclusion
- 句型整齐得像模型生成
- 为了教学硬塞短语
- 文章像考试材料，没有真实内容感

## 4. 教学检查

### 关键问题

- 停下来的地方真的值得讲吗？
- 最难的地方有没有讲？
- 核心观点有没有讲清？
- 是否帮助用户看见全文结构？
- 是否只盯词汇，没有讲逻辑？
- 是否把简单句复杂化？
- 是否一次讲太多？
- 是否准确预测了中国学习者的误解？
- 是否有必要重播的句子？

### 数量检查

- 停顿 6–10
- 深讲 3–4
- 表达 4–6
- 前后连接至少 2 次
- 误解预测至少 1 次
- 明确快速通过至少 1 次

数量不是绝对质量，但异常通常代表节奏失衡。

## 5. 讲稿检查

评分维度：

| 维度 | 5 分状态 |
|---|---|
| 原文忠实 | 无误解，无过度推断 |
| 教学取舍 | 重点少而准确 |
| 全文理解 | 用户能跟上文章推进 |
| 表达价值 | 讲的是可迁移且必要的表达 |
| 听觉自然 | 像人在自然说话 |
| 人格一致 | 全程同一个老师 |
| 信息密度 | 有轻有重，不累 |
| 活人感 | 有判断、回扣和阅读反应 |

### AI 腔扫描

搜索并人工检查：

- 我们来看
- 这里很有意思
- 简单来说
- 也就是说
- 其实
- 非常重要
- 地道表达
- 大家一定
- 恭喜你
- OK
- 那么

不是一律禁止，而是检查频率和模板化。

## 6. 音频试听

必须整篇连续播放。

### 检查项

- 教师声音是否稳定
- 原文朗读声音是否稳定
- 中英文切换是否突兀
- 人名、地名、缩写是否正确
- 数字和年份是否自然
- 句间停顿
- 片段拼接
- 音量一致
- 语速
- 情绪是否过度
- 讲稿文字自然但念出来别扭的地方
- 音频与高亮是否一致
- 重播是否播放正确原句

### 阻断问题

- 漏音频
- 音频引用错误
- 讲解和高亮错位
- 发音严重错误
- 明显声音人格变化
- 片段重复或顺序错误
- 无法播放或路径失效

## 7. 页面预览

分别检查：

- 桌面端
- 移动端
- 讲解模式
- 阅读模式
- 自动滚动开启
- 自动滚动关闭
- 用户手动滚动
- 模式切换
- 刷新恢复
- 倍速播放

## 8. 发布门槛

所有自动评分至少 4/5，且无阻断问题。

人工编辑者必须勾选：

```text
[ ] 事实已核对
[ ] 英文已审阅
[ ] 教学取舍合理
[ ] 讲稿已完整听过
[ ] 发音已检查
[ ] 高亮同步正确
[ ] 移动端已预览
[ ] 来源记录完整
[ ] 发布日期正确
```

## 9. 发布后数据

主要观察：

- 开始讲解率
- 25% / 50% / 75% / 100% 完成率
- 平均退出片段
- 被跳过最多的讲解片段
- 被重播最多的原文句子
- 阅读模式切换率
- 难度反馈
- 讲解密度反馈

不要只看总播放次数。

## 10. 早期人工迭代

前 20–30 篇课程必须人工完整试听。

每次修改记录原因：

```json
{
  "segmentId": "seg_09",
  "changeType": "REMOVE_REDUNDANCY",
  "before": "...",
  "after": "...",
  "reason": "Repeated the paragraph summary already explained in seg_07."
}
```

累积修改分类，用于优化 Prompt 和 few-shot 示例。

这些编辑记录是长期内容资产。
