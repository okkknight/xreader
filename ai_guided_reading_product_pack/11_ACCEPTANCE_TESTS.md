# 验收测试

## 1. 首页

### 今日文章

- [ ] 有已发布今日文章时，首页显示正确文章。
- [ ] 没有今日文章时，显示友好空状态。
- [ ] 不会错误显示未发布或未来文章。
- [ ] 开始讲解进入 `guided`。
- [ ] 自己阅读进入 `reading`。

## 2. 讲解模式

- [ ] 播放队列按 `order` 运行。
- [ ] `ARTICLE_READ` 使用原文声音。
- [ ] 讲解片段使用教师声音。
- [ ] 当前句子正确高亮。
- [ ] `REPLAY` 播放正确来源片段。
- [ ] 暂停后继续位置正确。
- [ ] 倍速生效。
- [ ] 前进和后退不会破坏片段状态。
- [ ] 讲解完成后显示结束状态。

## 3. 自动跟随

- [ ] 当前高亮在可视区时不滚动。
- [ ] 离开可视区时平滑滚动。
- [ ] 用户手动滚动后停止自动跟随。
- [ ] 显示“回到当前讲解”。
- [ ] 点击后恢复跟随。
- [ ] 减少动态效果设置下不强制平滑动画。

## 4. 阅读模式

- [ ] 可以连续播放全文。
- [ ] 可以点击句子播放。
- [ ] 当前句子高亮。
- [ ] 可以临时查看中文。
- [ ] 中文不会默认全部展开。
- [ ] 词组注释可点击。
- [ ] 切换到讲解模式定位到对应片段。

## 5. 进度

- [ ] 刷新后恢复文章位置。
- [ ] 讲解和阅读进度分别保存。
- [ ] 模式切换共享当前句子映射。
- [ ] 完成状态保存。
- [ ] 无账号也可工作。

## 6. 后台文章编辑

- [ ] 可以新建文章。
- [ ] 可以编辑标题、正文和元数据。
- [ ] 可以切分段落与句子。
- [ ] 句子拥有稳定 ID。
- [ ] 修改文章时提示下游内容可能过期。
- [ ] 可以导入和导出 JSON。
- [ ] 未授权不能进入后台。

## 7. 内容管线

- [ ] 每个步骤可独立运行。
- [ ] 每个步骤保存输入输出。
- [ ] 非法 JSON 被拒绝。
- [ ] Prompt 版本被记录。
- [ ] 模型和输入哈希被记录。
- [ ] AI 失败不会覆盖旧结果。
- [ ] 人工修改不会被静默覆盖。
- [ ] 可以从任意中间步骤重新运行。

## 8. 讲解片段

- [ ] 可以新增、删除和排序。
- [ ] 可以选择片段类型。
- [ ] 可以映射多个句子。
- [ ] 无效句子引用无法保存。
- [ ] `ARTICLE_READ` 必须有句子。
- [ ] 教师讲解必须有 script。
- [ ] 修改 script 后音频标记 stale。
- [ ] 可以单片试听。

## 9. Fish Audio

- [ ] API Key 只在服务端。
- [ ] 生成成功保存文件和时长。
- [ ] 请求失败记录错误。
- [ ] 支持重试。
- [ ] 相同文本和配置可避免重复请求。
- [ ] 教师与原文声音分开配置。
- [ ] 文件名不依赖原始用户文本。
- [ ] 路径不能逃逸存储目录。
- [ ] 文本修改后不会继续使用旧音频。

## 10. 发布

- [ ] 只有 QA_PASSED 或允许状态可发布。
- [ ] 发布前必须完成检查清单。
- [ ] 未发布内容公共 API 不可见。
- [ ] 撤回后公共端不再展示。
- [ ] 今日文章选择逻辑正确。
- [ ] 发布文章的所有片段都有可用音频。

## 11. 质量规则自动检查

- [ ] 停顿点不在 6–10 时提示。
- [ ] 深讲不在 3–4 时提示。
- [ ] 核心表达不在 4–6 时提示。
- [ ] 无前后连接时提示。
- [ ] 无误解预测时提示。
- [ ] 讲稿出现高频 AI 口头禅时提示。
- [ ] 重复讲解同一表达时提示。
- [ ] 总时长超出 8–12 分钟时提示。
- [ ] 句子映射断裂时阻止发布。

## 12. 移动端

- [ ] 播放器不遮挡正文。
- [ ] 模式切换易点击。
- [ ] 字体大小合适。
- [ ] 长标题不溢出。
- [ ] 高亮范围清楚。
- [ ] 页面滚动顺畅。
- [ ] 弱网下有音频加载状态。

## 13. 内容验收样例

发布前由人工回答：

- [ ] 文章本身值得读，不只是英语材料。
- [ ] 开场在 30 秒内进入主题。
- [ ] 老师没有平均讲解每句话。
- [ ] 至少一处让人感觉老师记得前文。
- [ ] 至少一处准确预测学习者误解。
- [ ] 老师没有虚构个人经历。
- [ ] 没有考试培训腔。
- [ ] 没有过度鼓励。
- [ ] 全篇听下来像一个人在连续讲。
- [ ] 用户即使不看字幕，也大致能跟上。
