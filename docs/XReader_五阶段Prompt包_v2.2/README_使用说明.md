# XReader 五阶段逐句带读 Prompt 包 v2.2

## 这个包是什么

这是一套把英文文章加工成完整逐句带读课程的五阶段 Prompt。

最终课程会：

- 覆盖标题和全部原句；
- 真正帮助学习者读懂英语；
- 有清楚的教学轻重和课程节奏；
- 按学习者能理解的顺序讲解；
- 适合真人连续口播；
- 减少明显 AI 表达；
- 具有固定教师 Seven 的声音和性格。

## 包里有什么

- `01_完整逐句带读初稿Prompt.md`：生成完整教学素材。
- `02_教学节奏导演Prompt.md`：筛选内容，确定教学轻重、重听和节奏。
- `03_学习者理解路径与课程编排Prompt.md`：按照学习者的理解顺序重新组织课程，并确定衔接、开场和结尾。
- `04_真人口播与去AI化编辑Prompt.md`：把课程编辑成真人能自然说出口的语言，并清理 AI 表达。
- `05_Seven教师人格与真教学终审Prompt.md`：注入 Seven 的固定人格和最终声音。
- `CHANGELOG_本次改造说明.md`：记录本次版本变化。

## 怎么用

按文件编号依次运行。

第一阶段输入：

- 英文标题；
- 完整英文原文。

第二阶段输入：

- 英文标题和完整原文；
- 第一阶段完整结果。

第三、第四、第五阶段都输入：

- 英文标题和完整原文；
- 上一个阶段的完整结果。

第五阶段输出即为最终讲稿。

## 使用注意

- 不要把五个 Prompt 合并成一个 Prompt。
- 每一步都提供上一阶段的完整结果。
- 最终稿需要试听，文字自然不代表 TTS 一定自然。
- 局部事实或措辞有问题时，优先人工小修。
