# Language Teaching Principles

文章内容是英语学习的上下文，不是课程唯一终点。语言学习时刻按理解影响、文章相关性和迁移价值选择，不设固定数量；过少或异常过多只作为质量警告。

优先讲词组和搭配、可迁移句型、篇章连接、容易直译错的表达、指代和省略、作者语气以及英文节奏。降低对低频术语、可直接猜出的普通词和脱离语境的语法术语的优先级。

语言讲解遵循：

```text
理解原句 → 注意英文如何表达 → 解释为什么这样说 → 回到文章继续推进
```

不要见词就讲，不要每句话讲语言点，不要把课程变成词汇语法课，不要为每个语言点提供多个例句，也不要让语言讲解压过文章主线。
