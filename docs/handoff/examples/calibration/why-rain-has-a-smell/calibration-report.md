# Calibration Report: why-rain-has-a-smell

## 对比结论

- 内容理解：新版保留全文因果链，并把“混合物—传播路径—敏感成分—植物油—地点差异”作为连续推进。
- 英语学习价值：新版明确讲解 `rather than`、`carry upward`、`at very low levels`、`build up`、`at once`、`drift away` 和 `small signature`，每次都回到文章任务。
- 教学必要性：旧版由字段深度决定停顿；新版每次展开都有文章理解或英语迁移理由。
- 教师判断：新版出现了明确取舍、表达澄清和对 `geosmin`/`petrichor` 的范围区分；旧版没有可见判断。
- 认知负担：新版将 p02 和 p05 的机制拆成不同学习负担，避免同一 Beat 堆叠多个语言点。
- 篇章节奏：新版允许普通句快速通过，在机制、限制和结论处放慢；旧版每句表面结构相同。
- 听觉自然：新版删除固定“接下来/我们接着看下一句”链条，讲解文本由 Codex 直接创作。
