# 项目交接入口

这是 XReader 的精简交接包，故意只保留一个上下文文件和一个追加式变更记录，避免与产品资料包形成重复事实源。

阅读顺序：

1. [PROJECT_CONTEXT.md](../../PROJECT_CONTEXT.md)：当前产品形态、实现状态、约束、风险和下一步。
2. [CODEX_WORKFLOW.md](CODEX_WORKFLOW.md)：当前唯一的 Codex 课程生产工作流。
3. [INSTRUCTIONAL_QUALITY_STANDARD.md](INSTRUCTIONAL_QUALITY_STANDARD.md)：课程教学质量合同、证据评分和返工门槛。
4. [COURSE_SCRIPT_GENERATION.md](COURSE_SCRIPT_GENERATION.md)：讲稿阶段产物和版本保存规则。
5. [COURSE_IMPORT.md](COURSE_IMPORT.md)：唯一的课程导入入口和边界。
6. [CHANGELOG.md](CHANGELOG.md)：交接包的 durable 变更记录。

产品规格、课程生产、数据校验和用户端行为以本交接目录和当前代码为准。
