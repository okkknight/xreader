# 项目交接入口

这是 XReader 的精简交接包，故意只保留一个上下文文件和一个追加式变更记录，避免与产品资料包形成重复事实源。

阅读顺序：

1. [PROJECT_CONTEXT.md](../../PROJECT_CONTEXT.md)：当前产品形态、实现状态、约束、风险和下一步。
2. [00_CODEX_START_HERE.md](../../ai_guided_reading_product_pack/00_CODEX_START_HERE.md)：原始资料包入口与实现原则。
3. [CHANGELOG.md](CHANGELOG.md)：交接包的 durable 变更记录。

实际产品规格、UX、架构、数据/API、Prompt、QA 和验收标准仍以 `ai_guided_reading_product_pack/` 中对应文件为准。
