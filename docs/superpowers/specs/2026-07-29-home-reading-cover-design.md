# 首页阅读封面设计

## 目标

将首页改成以“今日文章”为唯一焦点的沉浸式阅读封面，让用户一眼看见文章、理解主题，并选择讲解或直接阅读。

## 已确认的视觉方向

- 页面正文背景复用当前文章封面：同一张图片全屏放大、轻微柔焦、低强度深绿压暗后作为沉浸底色；原画的雨景、颜色与笔触仍应可辨，保留并提高现有顶部导航的浅色对比度。
- 顶部不再使用大字号“今日阅读”；仅保留不抢眼的页面语义标题供辅助功能使用。
- 首屏主体是一张居中的横向圆角插图卡片，桌面宽度约 64rem、16:9 左右；四周保留清晰的呼吸空间，手机改为更高的竖向卡片。
- 插图表现雨后干燥土壤、植物表面、细雨与空气中被带起的微粒；风格为克制的编辑插画，不在图片中生成文字。
- 标题、中文翻译和按钮由 HTML 叠放在卡片左下方；使用深绿遮罩保证白色文字可读。
- 主按钮维持当前进度语义：首次为“开始讲解”，有未完成进度时为“继续讲解”；次按钮固定为“先读文章”。
- 不新增营销文案、标签、卡片网格或装饰性数据。

## 组件与数据边界

- `TodayArticleFeature` 继续只接收 `PublicArticle`，负责进度文案、链接与卡片内容。
- 页面组件只负责传入当天文章和首页语义结构。
- 背景插图是项目内静态资源；文章标题和按钮不烘焙进图片，保证未来文章可复用同一组件。

## 验收标准

- 桌面和 390px 手机宽度下均可见完整标题、翻译和两个按钮。
- 主卡片图片、标题和操作形成明确层次，文字不与背景混淆。
- 模糊底图只作为环境氛围；清晰主图、标题和按钮保持最高视觉优先级。
- 两个链接继续分别进入默认讲解模式和 `?mode=reading`。
- 无运行时错误，无横向溢出；图片从项目静态资源加载。
