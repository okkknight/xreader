# 播放控制栏视觉重整设计

## 目标

让固定播放栏成为一个清晰的单一控制面：播放控制、当前讲解和速度设置各自有稳定区域，不再被大块空白和无意义装饰线分散。

## 设计

- 左侧控制组依次放置上一段、播放/暂停、下一段；三个按钮共享紧凑的边界与 hover/focus 状态。
- 中间内容区显示当前字幕，顶部显示“讲解播放”和当前片段序号，字幕超长时单行省略。
- 右侧显示速度标签与选择器；选择器保留现有 `0.75×`、`1×`、`1.25×` 行为。
- 保持现有 ARIA 标签、播放完成文案和事件回调，不改音频队列逻辑。
- 桌面端为一行、最大宽度与页面内容对齐；移动端改为两行，控制组和速度在第一行，字幕在第二行，不能横向溢出。
- 使用现有深绿色主题和系统字体，不引入图片或新依赖。

## 验收

- 桌面端控制栏视觉分组明确，按钮不会撑满无意义宽度。
- 移动端 390px 宽度下控制栏不溢出，字幕可读。
- 播放、暂停、前后段、完成文案和速度选择行为保持通过现有测试。
- 生产构建、单测和 Playwright 流程通过。
