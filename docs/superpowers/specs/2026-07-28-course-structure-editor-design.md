# XReader 课程结构编辑设计

## 当前缺口

后台可编辑现有句子和讲稿，但不能新增/删除片段、修改片段类型或句子映射，也没有 JSON 导入导出。因此手工编辑无法可靠地完成或交换一篇完整课程。

## 范围

在现有 `CourseImport` 草稿状态中实现：片段新增、删除、排序、类型/声音角色/主教学目标/讲稿/多句映射编辑；文章页导出完整 JSON 和导入完整 JSON。保存继续走现有 `PUT /api/admin/articles/[id]` 与 `validateCourse`，不会创建新的局部写入 API。

## 交互与约束

- 新片段默认 `QUICK_EXPLANATION`、`TEACHER`、空映射，并使用 `请填写讲解稿。` 作为可见待编辑稿，确保草稿可保存后再人工修改。
- 改为 `ARTICLE_READ` 时自动使用 `READER` 并清空讲稿；改为其他类型时使用 `TEACHER`，若无讲稿则填入待编辑稿。
- 句子映射使用当前文章稳定 ID 的多选框；删除片段后重排连续 order。
- 导入只接受同一 article id 的完整 `CourseImport` JSON；先在浏览器调用 `validateCourse` 的同构规则后放入草稿，用户仍须点“保存草稿”才写数据库。
- 导出不含来源、QA、音频资产或管理员 session，保持为可移植课程结构。

## 验收

- 管理员可新增、编辑、删除、排序片段并保存；无效映射无法通过 API 保存。
- 导出后导入同一 JSON，段落、句子、片段及 annotation ID 保持不变。
- 未授权用户仍无法调用文章保存 API。
