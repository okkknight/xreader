# XReader 五阶段逐句带读 Prompt 包

这套 Prompt 用于把任意英文文章逐步加工成一份适合中文学习者连续收听的逐句陪伴式带读讲稿。

## 核心定位

XReader 的课程不是文章摘要、中文内容解说、重点表达精选、考试式语法课或知识播客。

它是一节从标题开始，由老师陪学习者按照原文顺序，一句一句读完整篇文章的英语阅读课。

文章难度和题材可以不同，但授课方法不因等级而改变：简单句讲得短，复杂句讲得长；每句话都得到必要支持，但不是每句话都被拆成一堂小课。

## 五阶段流程

### 第一阶段：完整逐句带读初稿

输入英文标题与完整原文。确保标题和全部原句都被真正教到，建立完整、扎实的教学底稿。

### 第二阶段：教学节奏导演

输入原文与第一阶段讲稿。删除重复和低收益细节，建立快慢、停顿、回收和段落推进，同时保留逐句教学底盘。

### 第三阶段：真人口播终审

输入原文与第二阶段讲稿。减少教材腔，融合中文理解与英语讲解，改善中英文切换和连续听感。

### 第四阶段：开场与结尾微调

输入第三阶段讲稿。只补充很短的自然引子与有人味的课程收束，不重写正文。

### 第五阶段：学习负担与教师温度终审

输入原文与第四阶段讲稿。在真实难点、记忆压力、信息累积和学习状态切换处，加入低密度的教师理解，不哄学，不泛泛鼓励。

## 推荐执行原则

1. 每一阶段都使用上一阶段的完整结果，不要让模型凭记忆修改。
2. 第二、三、五阶段建议同时提供英文原文，以降低误删、漏句和篡改风险。
3. 每阶段只做自己的任务，不要让后续 Prompt 重新设计已经确定的内容。
4. 最终必须试听音频。文字自然不等于 TTS 一定自然。
5. 单个词义、事实或表达不准确时，直接人工小修，不要继续增加整轮全文重写。
6. 文章本身很短或很简单时，后续阶段应主动少改，不要为了显示工作量强行加工。
